# VARELLION — Product Requirements Document (PRD)

## 1. Executive Summary
- **Brand:** VARELLION
- **Target Market:** Egypt (national delivery across all 27 governorates)
- **Currency:** Egyptian Pound (EGP)
- **Primary Product Lines:**
  1. Luxury & Modern Watches (ساعات فاخرة)
  2. Genuine Leather Wallets & Cardholders (محافظ جلد طبيعي وحاملات بطاقات)
  3. Men's Lifestyle & Tech Accessories (إكسسوارات رجالية راقية)

## 2. Customer Value Proposition
- High perceived value and masculine elegance at accessible, transparent pricing.
- 100% genuine materials: full-grain leather, stainless steel, premium finishes.
- Guaranteed customer protection: inspection prior to payment (معاينة قبل الاستلام), 14-day return/exchange window, nationwide Cash on Delivery.

## 3. Core Storefront Features
1. **Header & Navigation:** Responsive, brand mark, category shortcuts, search, cart counter with drawer toggle, AR/EN language switcher.
2. **Hero Section & Conversion Formula:** Instant value proposition, 4 trust pillars, fast category entry points.
3. **Product Catalog:** Faceted filtering, sorting by price/popularity, real-time stock availability indicators.
4. **Product Details:** High-res gallery, zoom, variant selectors, direct Add to Cart and Express Checkout buttons.
5. **Cart Experience:** Optimistic slide-out drawer, item counter, free shipping progress bar, promo code input.
6. **Checkout Flow:** One-page checkout, 27 Egypt governorates with automatic shipping rates, COD and Card/Wallet payment options.
7. **Order Tracking:** Lookup order status by Order ID and Phone number.

## 4. Admin Management Features
1. **Executive Dashboard:** Total revenue, order count, pending shipments, low-stock warnings, sales trend charts.
2. **Product Catalog Management:** Data table with search/filter/pagination, create/edit modal form, stock adjustments.
3. **Order Processing:** Full order list, status update pipeline (PENDING -> PROCESSING -> SHIPPED -> DELIVERED -> CANCELLED), customer and shipping details.
4. **Customer Records:** Customer directory, order history, spending totals.
