# VARELLION Frontend (Next.js 15 + React 19 + TypeScript)

> الواجهة الأمامية لمتجر **VARELLION** الإلكتروني، مبنية باستخدام Next.js 15 (App Router) و React 19 و Tailwind CSS و TypeScript مع دعم كامل للغة العربية (RTL) والإنجليزية (LTR).

## 🚀 تشغيل بيئة التطوير المحلية (Local Development)

```bash
npm install
npm run dev
```

التطبيق سيعمل على المنفذ: `http://localhost:3000`

## 🧪 تشغيل الاختبارات الآلية (Testing)

```bash
npm run test
```

## 📁 هيكل المجلدات (Structure)
- `src/app`: صفحات ومسارات التطبيق (App Router)
- `src/components`: مكونات الواجهة (UI components, checkout, admin, orders, cart)
- `src/services`: خدمات الاتصال بالـ Backend APIs
- `src/context`: سياق السلة والمصادقة (CartContext, AuthContext)
- `src/styles`: إعدادات وتنسيقات Tailwind CSS الشاملة
- `docs/`: التوثيق المعماري وتدقيقات الـ UX والوصولية
- `skills/`: مهارات وأدوات وكلاء الذكاء الاصطناعي لتطوير الواجهات
- `_references/`: المشاريع المرجعية للفرونت إند
